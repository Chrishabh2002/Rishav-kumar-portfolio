## ✨ About This Portfolio

This site isn't a template — it's built from scratch as a demonstration of the same engineering it describes.

- **AI assistant, twice over** — an embedded chat that answers questions about my background. It talks to Claude or OpenAI when a key is configured, and falls back to a built-in résumé answer engine when neither is, so it always gives a real answer instead of an error.
- **Résumé as a shell** — an interactive terminal (`whoami`, `experience`, `projects`, `skills`, `education`, `contact`) with command history. On-brand, given I build command-execution agents for a living.
- **Ctrl+K command palette** — keyboard-driven navigation, résumé download, and copy-to-clipboard actions.
- **Animated skill dials** — 45+ technologies with real brand marks, SVG proficiency rings that fill on scroll, and category filtering.
- **Real company logos** — every organisation I've worked with, sourced from their official brand assets.
- **3D particle field** — a Three.js starfield that reacts to the cursor.
- **Motion throughout** — scroll-linked timeline, cursor spotlights, conic-gradient borders, and infinite marquees — all of it honouring `prefers-reduced-motion`.

### Architecture

Every piece of résumé content lives in a single typed source of truth (`lib/portfolio-data.ts`). The UI, the AI assistant's knowledge, the terminal, the sitemap, and the structured data all read from it — so nothing can drift out of sync.

```
app/
├── api/ai/chat/         # Edge route: Claude → OpenAI → offline fallback
├── components/          # Client components (hero, timeline, skills, terminal, …)
├── styles/effects.css   # Keyframes: aurora, orbit, marquee, conic borders
├── layout.tsx           # Metadata, JSON-LD graph, fonts
├── page.tsx             # Section composition
├── opengraph-image.tsx  # Generated 1200×630 social card
├── sitemap.ts           # Generated sitemap.xml
└── robots.ts            # Generated robots.txt
lib/
├── portfolio-data.ts    # Single source of truth for all résumé content
├── seo.ts               # Canonical URL, metadata copy, schema.org graph
└── utils.ts
public/
├── logos/               # Official company logos
└── Rishav-Kumar-Resume.pdf
```

### SEO

- schema.org `@graph` with cross-referenced `Person`, `WebSite`, `ProfilePage` and `ItemList` entities
- Generated `sitemap.xml` (root + section anchors) and `robots.txt`
- Dynamically generated Open Graph / Twitter card at 1200×630
- Canonical URL pinned to the production domain, independent of the deploy host
- Semantic heading hierarchy, descriptive alt text, and `preconnect` hints for third-party origins

## 🏃 Running Locally

**Requirements:** Node.js 20+ and npm.

```bash
git clone https://github.com/Chrishabh2002/Rishav-kumar-portfolio.git
cd Rishav-kumar-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Environment variables

Create a `.env` file in the project root. **It is gitignored — never commit real values.**

| Variable | Required | Purpose |
|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | No | Canonical public origin for SEO tags. Defaults to the production domain. |
| `NEXT_PUBLIC_BASE_URL` | No | Deploy host used by the Cosmic platform SDKs. |
| `ANTHROPIC_API_KEY` | No | Enables the AI assistant via Claude. Preferred when set. |
| `OPENAI_API_KEY` | No | Enables the AI assistant via OpenAI. Used if no Anthropic key is set. |
| `USER_ID` | No | Cosmic platform identifier. |
| `NEXT_PUBLIC_CLIENT_ID` | No | Cosmic client identifier. |
| `COSMICAUTH_SECRET` | No | Cosmic authentication secret. |
| `COSMIC_PAYMENTS_SECRET` | No | Cosmic payments secret. |
| `COSMIC_DATABASE_SECRET` | No | Cosmic database secret. |
| `COSMIC_FILES_SECRET` | No | Cosmic file storage secret. |

With no AI key set, the assistant automatically serves answers from its built-in résumé engine — the site works fully without any configuration.

### Scripts

| Command | Description |
|---|---|
| `npm run dev` | Start the development server |
| `npm run build` | Production build |
| `npm start` | Serve the production build |
| `npm run lint` | ESLint + `tsc --noEmit` |

### Updating content

Edit `lib/portfolio-data.ts` — experience, projects, skills, education and achievements all flow from there into every section, the AI assistant, the terminal and the structured data automatically.
